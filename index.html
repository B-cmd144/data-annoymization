Reference · what each metric means

k-anonymity

A dataset is k-anonymous when every combination of quasi-identifiers is shared by at least k records, so no record can be singled out from the rest of its class. Equivalence classes are the distinct QI tuples and their sizes form a distribution; the minimum size is the k that was actually achieved.

l-diversity

k-anonymity alone does not stop attribute disclosure: if every member of a class has the same disease, the class leaks it. l-diversity requires each equivalence class to contain at least l distinct values for every sensitive attribute (this app enforces full l-diversity).

t-closeness

A class whose sensitive distribution is skewed (e.g. 100% one disease) leaks far more than its size suggests. t-closeness bounds the distance between each class's sensitive-attribute distribution and the distribution of the whole table at t.

Methods implemented
  • Full generalization — a generalization hierarchy per QI (power-of-two interval widths for numeric, frequency-chunked groups for categorical) and a greedy lattice ascent + local descent that finds the least-generalized lattice satisfying k.
  • Mondrian — recursive median partitioning on the widest quasi-identifier, then minimal local generalization of each partition.
  • Hybrid — Mondrian first, then a global lattice applied only to the classes it could not make k-safe.
  • Data swapping — exchange sensitive values between classes to raise diversity while class sizes (and therefore k) stay intact.
  • Value repair — for t-closeness, one value at a time, each swap chosen to cut the worst over-threshold class the most for the least distortion.
Utility metrics
  • Information loss — mean normalized cell precision: interval width / domain range for numeric QIs, hierarchy level / depth for categorical QIs; sensitive-value edits are charged the same way.
  • Suppression rate — share of rows removed (and, separately, how many classes had to be dropped to reach l).
  • Cardinality reduction — distinct values per column, before vs after: the most intuitive proxy for how much signal survives.
Reading the charts
  • Class-size histogram — the mass must move right of the k line.
  • Per-class t-distance — every bar must sit under the t line.
  • k-sweep — the classic privacy/utility curve: push k right, information loss rises.
References: Sweeney (2002) k-anonymity; Machanavajjhala et al. (2007) l-diversity; El Emam et al. (2007) t-closeness; Elfakam et al. (2008) t-closeness hierarchy; Mondrian multi-dimensional de-identification; NIST SP 800-188 guidelines.
